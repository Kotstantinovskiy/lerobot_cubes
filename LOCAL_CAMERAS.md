## Выбор камеры

Выбирать по имени устройства, а не по числовому индексу: при переподключении порядок меняется.
Для ffmpeg / AVFoundation без звука:
- Стол: `Sport Cam:none`
- Рука: `Innomaker-U20CAM-1080p-S1:none`

Обе камеры успешно выдавали снимки 1920×1080. Для снимка пропускали первые 3–4 секунды потока.
Innomaker сначала выдавала чёрные кадры, затем изображение появилось; причина не установлена.

### LeRobot: исправление выбора устройств 17 сентября

В эпизоде `color_cubes_720p25` вместо камеры захвата под `wrist` записалась веб-камера с комнатой; содержимое видео подтверждает подмену. Верхняя дорожка правильная. Эпизод сохранён в `projects/color_cubes/camera_check/rejected-webcam-episode` и исключён из нового датасета.

В `projects/color_cubes/config.json` теперь используется `macos_device_name`: `Sport Cam` и `Innomaker-U20CAM-1080p-S1`. Локальный OpenCV-драйвер разрешает точное имя при каждом подключении, используя порядок OpenCV (сортировка по uniqueID), а не номера из списка ffmpeg. При отсутствии устройства запуск завершается ошибкой. Для этого установлен `pyobjc-framework-AVFoundation`.

Визуально проверенные свежие кадры: `projects/color_cubes/camera_check/named-devices/top.jpg` и `wrist.jpg`. Верхняя камера работает 1280×720, Innomaker — 1920×1080. В режиме 720p настоящая Innomaker при проверке не отдала кадры. Новая пара прошла 30-секундный замер чтения и сохранения без движения рук: 24,36 fps при целевых 25.
